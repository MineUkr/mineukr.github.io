Privacy Policy

Last updated: November 17, 2026

FoxEmpire Uploader ("the app") is a personal tool used only by the owner of the FoxEmpire YouTube channel.

What data the app uses

The app uses Google OAuth to access the owner's own YouTube account through the YouTube Data API, only to upload the owner's videos, post comments under them and read statistics of the owner's own videos.

Storage

The OAuth access token is stored only on the owner's own computer. No data is sold, shared with third parties or sent to any server other than Google's APIs.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
